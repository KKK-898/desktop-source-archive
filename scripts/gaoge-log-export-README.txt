高歌 Free — 中转解锁日志导出工具
==================================================

这个小工具用来把"高歌中转"在 Codex 里到底有没有生效，导出成一份
JSON 文件发给客服，方便定位问题。

它只读日志，不改任何设置：
  - 不会修改你的登录状态
  - 不会读取或上传账号、密码、API Key、聊天内容
  - 导出的文件只包含中转解锁的判断记录和版本信息


一、怎么用（包含两个文件的那种）
--------------------------------------------------

1. 先把压缩包解压出来（不要直接在压缩包里双击）。

2. 确保"高歌 Free"已经打开，并且 Codex 窗口也开着
   （只开高歌主界面、没开 Codex 窗口是不行的）。

3. 双击 export-fuel-log.bat

4. 窗口里出现"导出成功"就说明好了，
   按回车关闭窗口。JSON 文件已经在你的桌面上，名字类似：

       高歌中转日志-20261002-192128.json

5. 把这个 JSON 文件发给客服。


二、只有单个 exe 的那种
--------------------------------------------------

直接双击那个 exe，其余步骤同上。


三、如果失败了
--------------------------------------------------

窗口里会显示一段中文说明，里面最后一行会有一句给客服看的口令，
比如"CDP 端口连不上""WebSocket 连接失败"。

把那个窗口截个图，连那句口令一起发给客服就行。


四、常见情况
--------------------------------------------------

Q: 提示"没能连上 Codex 窗口"
A: 按提示检查三件事：高歌 Free 是否打开、Codex 窗口是否开着、
   "插件增强"是否处于开启状态。如果是刚打开 Codex，等十几秒
   让它完全加载好再试一次。

Q: Windows 弹出"已保护你的电脑"蓝色提示
A: 这个工具没有购买代码签名证书，属于正常现象。
   点"更多信息"→"仍要运行"即可。

Q: 找不着桌面上的文件
A: 文件名是"高歌中转日志-日期-时间.json"。
   如果你的桌面被 OneDrive 接管了，它也可能出现在
   OneDrive\桌面 里面。
